================================================================================
MOUNTING NOTES (from datasheet)
================================================================================

ANTENNA KEEPOUT:
- Top 4.4mm of module is antenna area
- No ground plane or copper within 5mm of antenna edge
- Module should extend beyond host PCB edge by 4.4mm minimum
- Or place at corner with 5mm clearance to ground plane

REFLOW SOLDERING:
- Maximum 2 reflow cycles
- Peak temperature: 230-250°C max
- Time above 220°C: 30 +20/-10 seconds

PIN 1 LOCATION:
- Pin A1 (P0.01) is at top-left of pad grid
- Bottom-left when viewing module from top with antenna at top

ALTIUM PCB FOOTPRINT CREATION STEPS

2. File > New > Library > PCB Library
3. Open script project: BC15C_Footprint.PrjScr
4. Run script: DXP > Run Script > CreateBC15CFootprint
5. Save library: File > Save As > BC15C.PcbLib
