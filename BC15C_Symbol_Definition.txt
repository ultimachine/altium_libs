ELECTRICAL SPECIFICATIONS

I/O Voltage: Up to 2.6V

Module Size: 6.0 x 12.4 mm (BC15C with chip antenna)

RF SPECIFICATIONS:
- BLE: 2Mbps, 1Mbps, 500kbps, 125kbps
- IEEE 802.15.4: 250 kbps
- TX Power: -8 dBm to +3 dBm
- RX Sensitivity: -98 dBm (1Mbps), -106 dBm (125kbps)

MCU:
- Nordic nRF54L15
- ARM Cortex M33 @ 128 MHz
- Flash: 1524KB
- RAM: 256KB

================================================================================
ALTIUM SCHEMATIC SYMBOL CREATION STEPS
================================================================================

1. Open Altium Designer
2. File > New > Library > Schematic Library
3. Place > Rectangle (600 mil x 1900 mil)
4. Place pins using the table above
5. Set pin properties:
   - Power pins (VDD, GND): Electrical Type = Power
   - Reset: Electrical Type = Input
   - SWDIO: Electrical Type = Bidirectional
   - SWDCLK: Electrical Type = Input
   - All GPIOs: Electrical Type = Passive
6. Add component parameters:
   - Comment = BC15C
   - Description = Fanstel BC15C BLE Module nRF54L15
7. Save as BC15C.SchLib
