================================================================================
MOUNTING NOTES (from datasheet)
================================================================================

ANTENNA:
- External antenna via u.FL connector at top of module
- Keep antenna area clear of ground plane

REFLOW SOLDERING:
- Maximum 2 reflow cycles
- Peak temperature: 230-250C max
- Time above 220C: 30 +20/-10 seconds

PIN 1 LOCATION:
- Pin 1 (ANT-SW) is at bottom-left when viewing module from top

================================================================================
ALTIUM PCB FOOTPRINT CREATION STEPS
================================================================================

1. Open Altium Designer
2. File > New > Library > PCB Library
3. Open script project: LR62E_Footprint.PrjScr
4. Run script: DXP > Run Script > CreateLR62EFootprint
5. After script completes:
   - Press V, D (View > Fit Document)
   - Press Ctrl+A (Select All)
   - Edit > Set Reference > Center
6. Save library: File > Save As > LR62E.PcbLib
