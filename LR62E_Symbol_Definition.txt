================================================================================
PIN TABLE (10 pins)
================================================================================

Pin#  | Name        | Type      | SX1262 Pin | Description
------|-------------|-----------|------------|---------------------------
1     | ANT-SW      | Passive   | -          | Antenna switch
2     | SX-NRESET   | Input     | 15         | Reset signal, active low
3     | BUSY        | Output    | 14         | Busy indicator
4     | DIO1        | IO        | 13         | Multiple purpose Digital IO
5     | VDD         | Power     | 1          | DC input voltage, 1.8V to 3.7V
6     | SCK         | Input     | 18         | SPI clock
7     | MOSI        | Input     | 17         | SPI Slave input
8     | MISO        | Output    | 16         | SPI Slave Output
9     | NSS         | Input     | 19         | SPI Slave Select
10    | GND         | Power     | 20         | Ground

================================================================================
ALTIUM SCHEMATIC SYMBOL CREATION STEPS
================================================================================

1. Open Altium Designer
2. File > New > Library > Schematic Library
3. Place > Rectangle (600 mil x 800 mil)
4. Place pins using the table above
5. Set pin properties:
   - Power pins (VDD, GND): Electrical Type = Power
   - Reset (SX-NRESET): Electrical Type = Input
   - BUSY: Electrical Type = Output
   - DIO1: Electrical Type = I/O
   - SPI pins (SCK, MOSI, NSS): Electrical Type = Input
   - MISO: Electrical Type = Output
   - ANT-SW: Electrical Type = Passive
6. Add component parameters:
   - Comment = LR62E
   - Description = Fanstel LR62E LoRa Module SX1262
7. Save as LR62E.SchLib
